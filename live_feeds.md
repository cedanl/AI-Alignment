# Live Feeds

> ℹ️ **Information:**
> A curated list of websites that deliver daily or weekly updates about AI
> benchmarks, AI news, and new AI research. Sources were verified live in
> August 2026. Details should be checked against the primary sources.

## Dutch Sources

- [ai.nl AI Nieuwsoverzicht](https://www.ai.nl/ai-nieuwsoverzicht) — A daily
  updated selection of AI and tech headlines in Dutch, grouped per day and
  kept for seven days. Sources include Tweakers, TechCrunch, The Verge, BBC
  Technology, and NU.nl.
- [NU.nl Tech](https://www.nu.nl/tech) — The technology section of the Dutch
  news site NU.nl, with regular AI and tech coverage.
- [AI Coalitie 4 NL (AIC4NL)](https://nlaic.com/nieuws) — The Dutch AI
  coalition for responsible AI. Publishes news on AI policy, the national AI
  agenda, the Nederlandse AI Fabriek, and the AI ecosystem.
- [SURF Nieuws](https://www.surf.nl/nieuws) — News from SURF, the ICT
  cooperative for Dutch education and research, including AI-related
  developments in higher education and research.
- [ICAI News](https://www.icai.ai/news) — News from the Innovation Center for
  Artificial Intelligence (UvA/VU Amsterdam), covering Dutch AI research,
  labs, and talent development.

> ⚠️ **Warning:**
> Some Dutch news sites and require accepting cookies or may limit access to articles.

  function frame(t) {
    if (lastTime === null) {
      lastTime = t;
    }
    var dt = t - lastTime;
    lastTime = t;
    if (running) {
      elapsed += dt;
      var progress = (elapsed / 1000 * 0.5) % 1;
      if (progress < prevProgress) {
        loopCount++;
        if (loopCount >= 5) {
          running = false;
        }
      }
      prevProgress = progress;
    }
    ctx.clearRect(0, 0, W, H);
    drawScene(elapsed);
    requestAnimationFrame(frame);
  }

  document.addEventListener("keydown", function (e) {
    if (e.code === "Space") {
      e.preventDefault();
      if (running) {
        running = false;
      } else {
        running = true;
        elapsed = 0;
        loopCount = 0;
        prevProgress = 0;
        lastTime = null;
      }
    }
  });

  requestAnimationFrame(frame);
